Excel Sheet Column Format & Guidelines

Follow the column headers below to ensure your Excel sheet is parsed accurately. For best results, use our pre-formatted template.

Column Header Required? Accepted Values & Data Type Sample Value Notes / Behavior
Product ID Optional Text (Alphanumeric) PROD_1727255400 Leave empty for new products. If provided, updates that existing product record.
Product Name Required Text (string) Fresh Organic Tomatoes English title of product. If matches existing product name, it will update it.
Tamil Name Optional Text (Unicode) நாட்டு தக்காளி Regional name for local customer search.
Category Recommended Text Vegetables Vegetables, Fruits, Greens, Dairy, Tender Coconut, etc. Defaults to Vegetables if empty.
Sub Category Optional Text Country, Organic Grouping tag inside category. Defaults to "General".
Selling Price Required Number (positive) 45 or 45.00 Live customer price in Indian Rupees (INR). Must be greater than 0.
MRP Optional Number 55 Original retail price before discount. Defaults to Selling Price if empty.
Cost Price Optional Number 35 Wholesale purchase cost. Used for profit analysis. Defaults to 80% of selling price.
Weight Recommended Number 500, 1, 250 Numeric pack size. Defaults to 500 for grams or 1 for kg/ltr/pack.
Unit Recommended grams, kg, pack, ltr, ml, pcs grams Unit of measurement. Defaults to grams.
Stock Mode Optional Market Sourced or Track Inventory Market Sourced Market Sourced = unlimited fresh daily sourcing. Track Inventory = limits purchase by stock count.
Stock Qty Optional Number 50 Initial physical stock. Relevant when Stock Mode is Track Inventory.
In Stock Optional Yes or No Yes Mark product currently available or out of stock. Defaults to Yes.
GST % Optional Number (0, 5, 12, 18) 5 Applicable GST percentage. Defaults to 5%.
Status Optional Active or Hidden Active Hidden items are saved in catalog but not shown to customers.
Subscription Optional Yes or No Yes Enables customer daily/alternate day repeat subscription orders. Defaults to No.
Next Day Delivery Optional Yes or No Yes Next morning 7 AM delivery slot. Defaults to Yes.
Immediate 10 Min Optional Yes or No No 10-minute instant delivery slot. Defaults to No.
Immediate 30 Min Optional Yes or No No 30-minute express delivery slot. Defaults to No.
Immediate 60 Min Optional Yes or No No 60-minute quick delivery slot. Defaults to No.
Delivery Days Optional All Days or comma-separated days Monday, Wednesday, Friday Restricts fulfillment to specific days. Outside these days, orders schedule forward. Defaults to All Days.
Image URL Optional URL or local asset path assets/categories/Thinkspot_veggiesIcon.png Defaults to standard category icon if left blank.
